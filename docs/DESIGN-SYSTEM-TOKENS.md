# Recipe Atelier design tokens

## Palette

- Parchment: `#F6F0E6`
- Porcelain: `#FFFDFC`
- Plum ink: `#2E1627`
- Cocoa: `#4B332B`
- Tomato: `#D85C43`
- Saffron: `#E2A742`
- Olive: `#66714A`
- Berry: `#8E405C`
- Charcoal laboratory: `#171318`

## Shape and depth

- Editorial cards: 24–32 px radius.
- Compact controls: 12–16 px radius.
- Borders: low-contrast cocoa or plum at 10–16 percent opacity.
- Shadows: broad, soft, and restrained; no glossy dashboard effects.

## Typography

- Editorial display: local serif stack.
- Interface and metadata: local humanist sans-serif stack.
- Recipes prioritize line length, hierarchy, and print readability over decorative type.

## Motion

- 160–240 ms transitions for hover, page, and selection states.
- Model progress uses measured download progress only where the runtime provides it; model reasoning remains stage-based.
- Reduced-motion preferences disable nonessential transforms and parallax.
