# Release checklist

- [ ] `npm run check` passes on the release commit.
- [ ] CI and GitHub Pages deployment succeed.
- [ ] Desktop/mobile keyboard and screen-reader smoke tests are recorded.
- [ ] Device backup/restore and deletion are tested.
- [ ] Supabase migration is applied to staging and all two-user negative RLS tests pass.
- [ ] Auth redirects, rate limits, email sender, recovery, and abuse controls are verified.
- [ ] Storage MIME, size, ownership, and signed-URL tests pass.
- [ ] Print proof, idempotency, webhook, pricing, refund, and shipping procedures are approved.
- [ ] Legacy identity, legal, audit, dispute, and reviewer procedures are approved.
- [ ] Privacy notice, terms, retention schedule, subprocessors, and incident plan receive counsel review.
- [ ] Formal trademark clearance is complete for the final name.
- [ ] Beta users have tested real family workflows and consented to handling of sensitive stories and media.
