# Dribbble-informed design research

The redesign studies recurring patterns in contemporary culinary-product presentations: oversized editorial typography, asymmetric food imagery, tactile paper-like surfaces, restrained color systems, strong recipe metadata, layered cards, and focused mobile task flows.

Mangrok applies those patterns through an original implementation. The repository does not copy a Dribbble shot, template, proprietary component, marketplace asset, or third-party illustration.

## Chosen product direction

### Recipe Atelier

Vault, discovery, reference recipes, and Print Studio use warm cream and parchment surfaces, deep plum typography, saffron and tomato accents, generous image-led cards, and cookbook-like hierarchy.

### Alchemy Laboratory

Alchemy retains the same functionality but uses a darker plum and charcoal workspace with brighter status surfaces for model progress, formula state, risk review, and recipe evolution.

### Authentic content presentation

Starter recipes are shown as source-aware editorial references. Each reference exposes region, tradition, source notes, adaptation notes, allergens, equipment, time, and editable lineage.

### Mobile behavior

The existing fitted app shell, keyboard handling, page navigation, progress sheet, cancellation, and local-model fallback remain unchanged. The redesign improves spacing, card density, image ratios, and information hierarchy without reintroducing page-level horizontal overflow.
