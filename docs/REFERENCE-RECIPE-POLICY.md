# Reference recipe policy

Mangrok reference recipes are editable educational starting points. They are not claims that one fixed recipe is the only authentic expression of a dish or culinary tradition.

Each reference record must include:

- a stable reference ID and review date;
- dish name, region, cuisine or tradition, and contextual note;
- independently written ingredients and method;
- allergen and dietary information;
- equipment and technique metadata;
- source names and source links;
- an adaptation note describing what Mangrok standardized;
- an original Mangrok illustration or a project-owned image.

A reference recipe is immutable. Selecting **Use as a starting point** creates a private editable copy and records the reference ID in recipe lineage. User edits never overwrite the reference source.

Safety-sensitive statements must be grounded in Mangrok's deterministic safety layer or an authoritative cited source. Reference recipes must avoid presenting approximate visual cues as proof of safe doneness.
