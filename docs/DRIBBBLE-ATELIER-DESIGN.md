# Mangrok Recipe Atelier visual direction

Mangrok uses an original visual system informed by contemporary editorial food, cookbook, and culinary-product interface patterns. It does not copy a Dribbble shot, paid template, proprietary component library, or third-party artwork.

## Visual language

- Warm parchment, cream, saffron, tomato, cocoa, and deep-plum surfaces.
- Large editorial recipe photography and original culinary illustrations.
- Clear text controls rather than symbol-only navigation.
- A light recipe-atelier mode for Vault, discovery, and Print Studio.
- A dark culinary-laboratory mode for Alchemy, model progress, risk review, and recipe evolution.
- Mobile pages remain viewport-fitted, keyboard-aware, and navigated through the existing app shell.

## Functional boundary

The redesign preserves recipe encryption, sealed notes, local storage, cloud adapters, sharing roles, backups, printing, Alchemy rules, WebLLM, self-hosted OpenAI-compatible models, the private AI gateway, entitlement handling, and mobile behavior.

## Reference recipes

Starter recipes are editorial reference implementations, not claims that one fixed version represents an entire culture. Each record stores region or tradition, source names and links, adaptation notes, allergens, equipment, ingredients, steps, and a review date. Cloning a reference creates an editable private recipe and leaves the source record unchanged.

## Image policy

Recipe and ingredient artwork is original Mangrok artwork or a project-owned asset. Dribbble is used for design research only. Marketplace images and shot assets are not copied into the repository.
