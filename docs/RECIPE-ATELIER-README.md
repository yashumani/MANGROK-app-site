# Mangrok Recipe Atelier

This release turns the recipe experience into an editorial atelier while preserving the working application underneath it.

The Vault becomes a place to discover, preserve, and personalize recipes. Alchemy remains a darker culinary laboratory where the same ingredients, equipment, local WebLLM, self-hosted model, deterministic engine, progress, cancellation, and safe fallback continue operating.

The Reference Table provides source-aware starter recipes that can be cloned into private editable records. It is intended to demonstrate the full recipe format and give new users a trustworthy starting point without claiming that any one standardized version is universally authentic.
