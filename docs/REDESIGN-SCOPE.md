# Redesign scope

The Recipe Atelier release changes presentation and reference content while preserving product behavior.

## Included

- Original warm editorial design system.
- Dark Alchemy laboratory treatment.
- Image-led reference recipe table.
- Immutable, source-aware starter recipes.
- Private editable cloning and recipe lineage.
- Original recipe artwork.
- Mobile and accessibility refinements.
- Repair of the ingredient-catalog dependency graph required by the existing kitchen library.

## Preserved

- Recipe Vault and local-first storage.
- Encryption and sealed notes.
- Sharing roles and trusted circles.
- Backups and restoration.
- Print Studio and secret-print safeguards.
- Legacy-review safeguards.
- Deterministic Alchemy engine.
- WebLLM, self-hosted OpenAI-compatible model, and private gateway adapters.
- Entitlement and trial behavior.
- Mobile app shell, keyboard handling, cancellation, and fallback.

## Not implied

- Generated imagery is not proof of a physically tested result.
- A reference recipe is not the only authentic version of a dish.
- The public static website does not activate production Supabase, billing, or private model hosting by itself.
