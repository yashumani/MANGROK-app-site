# Starter recipe research and sourcing

Mangrok's starter collection is an editorial reference table, not a set of claims that one standardized recipe is the sole authentic version of a dish.

The collection is designed around these source classes:

1. National or regional cultural and food-promotion organizations.
2. UNESCO or other cultural-heritage documentation where a dish or practice is formally described.
3. Established culinary institutions and public educational sources.
4. Multiple reputable secondary references when no authoritative single recipe exists.

Recipe wording is independently written for Mangrok. Source pages are used to verify dish identity, characteristic ingredients, technique, cultural context, and common variations; their prose and recipe instructions are not copied.

Every starter record includes a contextual note and an adaptation note. Regional variation is expected. Users clone a reference into a private recipe before changing it, preserving both provenance and personal evolution.

High-risk food-safety facts are not inferred from cultural sources. They remain governed by Mangrok's deterministic risk layer and independently verified guidance.
